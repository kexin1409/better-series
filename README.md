# 高性价比 · 循证科普系列

> 用最少的钱、时间和毅力，换回最确定的健康与财富。不贩卖焦虑，只给可溯源的证据。

「高性价比」是一套**循证生活决策**电子书：把市面上互相矛盾、动辄贩卖焦虑的养生 / 理财 / 保健内容，筛成一份**按性价比排好、每条可溯源**的备选单。你不必全做——挑走一两条就算数。

---

## 这套书怎么读

- 每一条建议都是一张**标准卡片**，固定 7 个字段：
  **成本**（钱 / 时间 / 毅力）· **说人话**（一句话讲清）· **收益**（大 / 中 / 小）· **证据等级**（A 强 / B 中 / C 弱）· **风险**（低 / 中 / 高）· **来源**（书 / 论文 / 官方文件）· **备注**
- 阅读页顶部可按 **性价比 / 证据等级 / 风险** 筛选，支持全文搜索
- 单文件 HTML，零依赖，**手机 / 断网可读**
- 每条都注明出处；结论可能过时或有错，决策请独立作出

### 1. 《高性价比饮食指南》
> 用最少的钱、时间和毅力，换回最多的健康

- **你会读到**：① 蛋白质 / 碳水 / 脂肪的循证结论与每餐怎么搭 ② 哪些"健康食品"其实是智商税 ③ 外卖、预制菜怎么选 ④ 高血压、糖尿病等慢病的饮食红线 ⑤ 补剂到底要不要买
- **规格**：13 节 · 127 条 · 证据 A31 / B71 / C25
